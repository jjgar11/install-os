# Guia de instalacion

```bash
sudo apt install git
git clone https://github.com/jjgar11/install-os.git ~/install-os
source ~/install-os/install.sh
```

Cerrar la sesion y volver a iniciar, abrir la terminal y luego para una configuracion rapida de OMZ oprimir ***1*** y ***Y*** hasta el final.
Luego de esto se hace

```bash
omz reload
```
